# Day 3 — VLOOKUP vs pandas merge in 60 Seconds #Shorts

Companion files for **VLOOKUP vs pandas merge in 60 Seconds #Shorts** on **TheDataScientist | Renjith R** (Python for Data Analysts, Day 3).

A made-up shop has 5,000 orders and a 200-product price list. Excel fills prices with 5,000 dragged `VLOOKUP` formulas; pandas does the same join in one line. All 5,000 prices match, and `indicator=True` flags the same 12 unknown product IDs that Excel shows as `#N/A`.

All data is synthetic and generated by `make_data.py` (seeded; see `DATA_FINGERPRINTS.txt`).

| File | What it does |
|---|---|
| `make_data.py` | 5,000 orders + 200 products; writes the CSVs and `data/orders_with_vlookup.xlsx` with 5,000 real `=VLOOKUP(...)` formulas |
| `merge_demo.py` | `orders.merge(products, on='product_id', how='left', indicator=True)`, then LibreOffice recalculates the Excel file and compares row by row |
| `run_all.sh` | Runs both scripts |
| `data/orders.csv`, `data/products.csv` | The seeded synthetic tables |
| `output/` | `orders_merged.csv`, `orders_missing_product.csv`, and the run logs that match the video |

## Run

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install pandas openpyxl
./run_all.sh                                           # or: PY=python3 ./run_all.sh
```

The pre-built `.xlsx` workbooks are not stored in the repo. `./run_all.sh` rebuilds `data/orders_with_vlookup.xlsx`. If LibreOffice (`soffice`) is installed, it also recalculates that workbook so the script can compare every VLOOKUP price to the merge.
