# Day 2 — AI vs Machine Learning vs Data Science, explained with one real example

Companion files for **AI vs Machine Learning vs Data Science: Explained with One Real Example** on **TheDataScientist | Renjith R**.

Masala Mart is a made-up online grocery shop in Pune, Jaipur, Kochi and Lucknow. All orders are generated by `make_data.py` (seeded, so every run gives the same file; see `DATA_FINGERPRINTS.txt`).
Two problems are planted, and the truth lives only in `_answer_key/` (no script reads it until grading):
1. a coupon-abuse ring in Pune from 15 Sep 2026 (new account every order, FIRST100 welcome coupon, mostly late at night, 6 shared drop addresses);
2. a courier change in Kochi on 1 Oct 2026 (delivery cost about Rs 45 -> Rs 72 per order).

| Step | File | What it shows |
|---|---|---|
| data | `make_data.py` | 15,062 history orders (1 Aug–31 Oct) + 2,607 "live" orders (1–14 Nov) |
| 1. Data science | `01_data_science.py` | group / compare / explain: finds both problems (no model) |
| 2. Machine learning | `02_machine_learning.py` | Isolation Forest trained on Aug+Sep without labels; October graded with the answer key |
| 3. AI | `03_ai_system.py` | a system that APPROVEs or HOLDs every new coupon order by itself: (A) hand-written rule vs (B) ML-powered |
| charts | `04_charts.py` | the three charts used in the video |
| tests | `tests/test_demo.py` | 5 checks (reproducible data, answer key hidden, both causes found, recall ≥ 80%, ML holds fewer genuine customers) |

## Run

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
./run_all.sh                                           # or: PY=python3 ./run_all.sh
```

`./run_all.sh` writes the synthetic orders to `data/` and rebuilds the outputs (the generator is seeded, so the data matches the video). Chart images are produced by `04_charts.py`.
