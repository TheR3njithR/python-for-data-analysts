# Day 7 — Replace a Pivot Table with 1 Line of pandas #Shorts

Companion files for **Replace a Pivot Table with 1 Line of pandas #Shorts** on **TheDataScientist | Renjith R** (Python for Data Analysts, Day 7).

A made-up shop has 3,000 sales across 6 regions and 10 months. pandas builds the same region-by-month totals as an Excel pivot in one line. All 60 cells match 60 Excel SUMIFS formulas recalculated by LibreOffice.

All data is synthetic and generated by `make_data.py` (seeded).

| File | What it does |
|---|---|
| `make_data.py` | 3,000 sales rows; writes `data/sales.csv` and `data/sales_with_sumifs.xlsx` with 60 real `=SUMIFS(...)` formulas |
| `pivot_demo.py` | `df.pivot_table(index='region', columns='month', values='amount', aggfunc='sum', margins=True)`, then LibreOffice recalculates the Excel file and compares cell by cell |
| `run_all.sh` | Runs both scripts |
| `data/sales.csv` | The seeded synthetic table |
| `output/` | `pivot.csv` and the run logs that match the video |

## Run

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
./run_all.sh                                           # or: PY=python3 ./run_all.sh
```

The pre-built `.xlsx` workbooks are not stored in the repo. `./run_all.sh` rebuilds `data/sales_with_sumifs.xlsx`. If LibreOffice (`soffice`) is installed, it also recalculates that workbook so the script can compare every SUMIFS total to the pivot.
