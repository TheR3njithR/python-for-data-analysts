# Python for Data Analysts

Companion repository for the **Python for Data Analysts** series on **TheDataScientist | Renjith R**, and for Daily Growth demos that share this repo.

Each day's folder has the code, synthetic data and tests from that video. Open the folder for the day you are watching, then follow its README.

| Day | Folder | Video |
|---|---|---|
| 1 | [day01-excel-to-python](./day01-excel-to-python) | [Automate Excel with Python: Your Monthly Report in One Command (Beginner)](https://youtu.be/L3rOE91lP8o) |
| 2 | [day02-ai-vs-ml-vs-ds](./day02-ai-vs-ml-vs-ds) | AI vs Machine Learning vs Data Science: Explained with One Real Example |

## Notes

- All data in this repository is synthetic. No real people, accounts or credentials.
- Educational code. Not financial advice.
- Large binary outputs (Excel workbooks, the Day 5 1 GB CSV and Parquet file) are not stored in the repo. Run `./run_all.sh` in the day's folder to rebuild them.
